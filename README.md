# eLine — электронная запись студентов

Веб-сервис электронной записи студентов на услуги университета.
Система предназначена для подачи, обработки и контроля заявок студентов, а также для управления расписанием и доступными временными интервалами.

## Назначение

В системе предусмотрены три роли пользователей:
- **Студент** — работа с услугами, расписанием и собственными заявками.
- **Сотрудник** — обработка заявок студентов и расширенная работа с расписанием.
- **Администратор** — все возможности сотрудника и дополнительные административные функции.

Модель доступа построена по принципу:
**Студент → Сотрудник → Администратор**
Фактический доступ к операциям определяется серверной проверкой роли пользователя.

## Основные возможности

### Студент

- просмотр доступных услуг;
- просмотр расписания;
- выбор даты и времени;
- создание заявки;
- просмотр собственных заявок;
- просмотр статуса заявки;
- просмотр информации о записи;
- удаление заявки в разрешённых состояниях.

### Сотрудник

- просмотр заявок студентов;
- поиск заявок;
- фильтрация по статусу;
- сортировка заявок;
- просмотр подробной информации;
- подтверждение и отклонение заявок;
- изменение статуса;
- принятие заявки в работу;
- назначение ответственного сотрудника;
- перенос записи;
- добавление административных комментариев;
- просмотр истории изменений;
- управление доступностью временных интервалов.

### Администратор

Администратор имеет возможности сотрудника и дополнительные административные функции:
- управление расписанием;
- автоматическая генерация расписания;
- выполнение административных операций.

В дальнейшем предусмотрено расширение административной части для управления услугами, сотрудниками и ролями пользователей.

## Архитектура

Проект построен по клиент-серверной архитектуре:

**React → PHP API → MySQL**

### Frontend

Клиентская часть реализована с использованием:
- React;
- JavaScript;
- Vite;
- HTML;
- CSS.

Frontend отвечает за интерфейс, навигацию, состояние приложения и взаимодействие с API.

### Backend

Серверная часть реализована на PHP.
Backend отвечает за:
- авторизацию;
- управление сессиями;
- проверку ролей;
- бизнес-логику;
- обработку API-запросов;
- работу с MySQL.

Для работы с базой данных используется PDO.

### Database

Для хранения данных используется MySQL.
В базе хранятся:
- пользователи;
- услуги;
- расписание;
- временные интервалы;
- заявки;
- статусы заявок;
- история изменений;
- административные комментарии;
- ответственные сотрудники.

## API

React не подключается напрямую к MySQL.
Все операции выполняются через PHP API.
Основные API-методы:

| API | Назначение |
|---|---|
| `getCurrentUser.php` | Получение текущего пользователя |
| `getServices.php` | Получение списка услуг |
| `getSchedule.php` | Получение доступного расписания |
| `addRequest.php` | Создание заявки |
| `getRequests.php` | Получение заявок |
| `updateRequest.php` | Изменение заявки |
| `deleteRequest.php` | Удаление заявки |
| `moveRequest.php` | Перенос записи |
| `getRequestHistoryByID.php` | Получение истории заявки |
| `getScheduleAdmin.php` | Расширенное расписание |
| `updateScheduleFieldisActive.php` | Управление доступностью времени |
| `addScheduleGenerator.php` | Генерация расписания |
